# 系统设置

## 端口设置

| 项 | 说明 |
| --- | --- |
| 代理端口 | Cursor 连到本机时用的端口。填 `0` 或不填时自动挑选可用端口；被占用时也会自动改用可用端口 |
| 服务端口 | 本机服务自身监听的端口，规则同上 |

修改后需要**重启应用**才生效，界面会提示「端口设置已保存，重启软件后生效」。

## 代理设置

| 模式 | 行为 |
| --- | --- |
| 默认 | 沿用系统代理设置 |
| 自定义 | 填自己的出站代理地址，可选用户名/密码 |

代理只影响 cursor-byok 访问上游模型服务的方式，不影响 Cursor 与本机服务的连接。不要把代理指到自己（会出现自引用错误）。

## 外部 API

打开 **开启外部 API** 后，本机应用和插件可以用「基础地址 + API 密钥」调用你已经配置好的模型，包括插件模型。

- 开启后所有外部请求都必须带这个密钥
- 基础地址按界面显示的值填入客户端
- 不使用时保持关闭，减少暴露面

## 定价

用于估算会话费用，单位是**每百万 token**：

| 项 | 默认 |
| --- | --- |
| 输入价格 | 5 |
| 输出价格 | 25 |
| 缓存读取价格 | 0.5 |
| 缓存写入价格 | 6.25 |

按你实际使用的模型服务价目表改，改完点 **保存**；**恢复默认** 会回到上表的值。定价只影响统计里的估算金额，不影响实际计费。

## Commit 提交代码模型设置

控制 Cursor 里生成提交信息（commit message）用哪个模型：

- **生成模型**：选一个已配置的模型，或选 **直连** 用 Cursor 官方服务生成
- **提示词设置**：自定义生成提交信息的提示词，可按界面语言分别设置

## 应用设置

| 项 | 说明 |
| --- | --- |
| 开机启动 | 登录系统后自动启动 cursor-byok |
| 静默启动 | 启动时不显示窗口 |
| Dock 栏图标 | macOS 下是否在 Dock 显示图标 |

同一页还会显示当前版本，有新版本时可直接检查更新。

## 插件配置

**插件配置** 页管理内置插件（如 Codex、Grok 账号授权）。插件可以用你配置的模型，也可以通过 OAuth 授权第三方账号。插件运行时会下载并固定 Deno 运行时版本，首次使用需要网络。

## 统计数据

系统设置里可以清理统计数据或详细记录，清理后不可恢复；已产生的调用记录与估算金额会一并消失，模型配置不受影响。
