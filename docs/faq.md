# 常见问题

## 能和 Cursor 官方账号同时用吗

可以。直接在 Cursor 里登录你自己的账号，官方额度和自定义模型可以随时切换：

- 官方模型走 Cursor 订阅额度
- 自定义模型走你配置的通道，费用由上游服务商计
- **Auto 只使用官方模型**，不会自动切到自定义模型
- 插件、代码库索引等 Cursor 功能照常可用

如果以前用旧版生成过 fake 账号，先退出该账号再登录自己的。

## 为什么选 Auto 时没用我的模型

这是 Cursor 的行为：Auto 由官方路由。请手动在模型列表里选择你配置的模型。

## 我的数据会上传到哪里

- API Key、模型配置、会话与用量数据都保存在本机 `~/.cursor-byok-v3`
- 模型请求会发给你配置的上游服务商，遵循该服务商的隐私政策
- cursor-byok 不会把你的凭据发到任何第三方；仓库代码可以自行审计

## TAB 补全为什么不用我的模型

Tab 补全由 Cursor 的独立 TAB 服务提供，不经过模型通道。见 [TAB 补全](./tab.md)。

## 1.0.3 为什么收不到更新

1.0.3 及更早版本的更新检查指向已归档的上游仓库，那里不会再有新版本。手动安装一次 1.0.4 后，更新检查才会指向本仓库。详见[从旧版本升级](./install.md#从旧版本升级)。

## 公共 TAB 服务怎么没了

早期版本有一个作者部署的公共 TAB 服务，随上游归档已停止。1.0.4 起移除该选项，已有配置会回落到 **直连**。需要的话可以自建，见 [TAB 补全](./tab.md)。

## 支持哪些模型服务

任何兼容 OpenAI Responses、OpenAI Chat Completions 或 Anthropic Messages 的服务都可以。能不能用工具调用、多轮和缓存，取决于上游是否实现了对应能力。

## 会不会更省钱

取决于你用的上游和服务商定价。cursor-byok 只做转发，不加价也不抽成；界面里的「估算价值」按你自己填的定价计算，不是账单。

## 怎么清空本地数据

退出 Cursor 和 cursor-byok，删除 `~/.cursor-byok-v3`，并删除系统里安装的 `Cursor BYOK Local CA` 证书。下次启动会重新生成 CA，需要重新授权。

## 遇到问题怎么反馈

到 [Issues](https://github.com/dengfuping/cursor-byok/issues) 搜索是否已有相同问题；没有就新开一个，附上操作系统、两个版本号、报错文本和复现步骤。请勿粘贴密钥或 `ca.key`。
