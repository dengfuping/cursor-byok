# 模型通道

每个模型配置是一条独立的上游通道：自己的地址、凭据、协议和生成参数。Cursor 模型选择器里会多出这些模型。

## 选类型和协议

| 你的上游 | 模型类型 | 请求协议 |
| --- | --- | --- |
| Claude 系列 | Anthropic | Messages API |
| GPT / OpenAI 系列 | OpenAI | **Responses API** |
| 其他兼容 OpenAI 的服务 | OpenAI | Chat Completions API |

::: tip 为什么 GPT 优先 Responses
Chat Completions 可能拿不到提示词缓存，速度和费用都会差一截。只有上游不支持 Responses 时才退回 Chat Completions。
:::

**模型类型**只决定请求与响应的格式；**请求协议**只决定路径追加方式，不会改变你填的地址本身。

## 字段说明

| 字段 | 说明 |
| --- | --- |
| 模型类型 | OpenAI 或 Anthropic |
| 请求协议 | OpenAI 类型下再选 Responses / Chat Completions |
| 服务器地址 | 填基础地址，应用按协议追加标准端点；勾选 **使用完整请求地址** 则原样使用，不追加不改写 |
| API Key | 上游要求的密钥，只保存在本机 |
| 模型名称 | 上游接口认的模型标识，可用 **获取模型** 读取上游模型列表 |
| 显示名称 | 只在 Cursor 模型列表里显示，不影响发给上游的标识 |
| 备注 | 显示在 Cursor 的模型说明里 |
| 上下文窗口 Token | 留空使用默认值 |
| 最大输出 Token | 留空使用默认值 |
| 推理强度 / 思考强度 | 按上游支持的取值填写 |
| 自定义 Headers | JSON 对象，只填上游明确支持的字段 |
| 额外参数 | JSON 对象，透传给上游请求体 |

## 测试

保存后点 **测试**，会真的发一次请求，报告首字延迟、生成速度和原始响应。也可以用 **一键测试** 批量跑，或用 **取消全部测试** 中断。

测试通过再回 Cursor 里用。测试失败时先看原始响应：401/404 通常是地址或密钥问题，模型不存在则是模型名称问题。

## 分组

**分组名称** 会应用到同组全部模型，并作为 Cursor 模型选择器中的徽章标签；清空则恢复显示服务器域名。**分组设置** 里改服务器地址会应用到该组全部模型，留空表示保持各模型现有配置不变。

## 顺序与复制

模型可以拖动排序、复制、批量编辑。排序只影响界面展示顺序，不影响请求。
